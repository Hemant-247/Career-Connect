# Career Connect


A full-stack career connect built using React.js, Supabase,
Clerk, Tailwind CSS and Shadcn UI.

## Features

- User authentication and authorization
- Browse available jobs
- Search and filter jobs
- View job details
- Apply for jobs
- Recruiter job posting and management
- Responsive user interface

## Tech Stack

- React.js
- Tailwind CSS
- Supabase
- Clerk
- Shadcn UI
- JavaScript

## Project Overview

This project provides a platform where users can explore job opportunities
and apply for suitable positions. Recruiters can post and manage job
openings through the platform.

## Authentication

Clerk is used for user authentication and managing user sessions.

## Database

Supabase is used for storing and managing application data.
